# Game Studio 4.0

Game Studio 4.0 links the existing content, mission, narrative, strategic, siege, cinematic and audio authoring workflows rather than introducing another project format.

## Acceptance gate

- Three authored missions and two meaningful branches
- Multiple authored actors and one playable multi-front siege
- Narrative consequences linked to verified tactical actions
- Camera/dialogue/audio playback and two different endings
- Validation, playtest, save/reload and export without hand-editing JSON

The workspace must show incoming and outgoing references for every resource, support searching across resource types, and surface unresolved references and missing asset files before export.

Build increments: 3.3.1 workspace; 3.3.2 narrative/strategic action bridge; 3.3.3 campaign and siege flows; 3.3.4 cinematic+audio triggers; 3.3.5 cross-editor playtest and undo/redo; 3.3.6 validated portable export.
